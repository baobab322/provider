# Система управления интернет-провайдером

Приложение с графическим интерфейсом на Python/Tkinter для автоматизации работы интернет-провайдера: учёт абонентов, договоров, тарифов, платежей и формирование отчётов.

## Функциональные возможности

- **Управление абонентами** — добавление, редактирование, удаление и поиск абонентов.
- **Договоры** — создание договоров, привязка абонента к тарифу, проверка баланса.
- **Тарифы** — добавление, редактирование и удаление тарифных планов.
- **Платежи** — внесение платежей по договору, просмотр истории платежей.
- **Отчёты** — формирование отчёта по платежам за выбранный месяц.
- **Звуковое сопровождение** — звуковые эффекты при различных действиях (вкл/выкл).
- **Хранение данных** — SQLite база данных со всеми необходимыми таблицами.

## Технологии

- Python 3
- Tkinter (графический интерфейс)
- SQLite (база данных)
- winsound (звуки на Windows)

## Установка и запуск

### Требования
- Установленный Python 3.6 или выше
- Операционная система Windows (для звуков `winsound`, на Linux/Mac звуки не будут работать, но программа запустится)

### Шаги

1. **Скачайте** файл `isp_system_gui.py`.

2. **Убедитесь**, что Python добавлен в PATH.

3. **Запустите** программу:
   ```bash
   python isp_system_gui.py
